BIOS TOP-LEVEL SHIELD ICON PACKAGE
==================================

This package is exclusively for the top-level BIOS corporate brand. It is derived from the approved complete-logo master and does not use any BIOS Marketing & Creative colors.

REFERENCE-MATCHED COLORS
- Navy mark: #010E23
- Dark-mode background: #091124
- Slate wave and lower shield: #607DA3
- White: #FFFFFF

USAGE
- Light backgrounds: use svg/bios-shield-mark-for-light-backgrounds.svg.
- Dark backgrounds: use svg/bios-shield-mark-for-dark-backgrounds.svg.
- Light-mode app tiles: choose a filename ending in -light.svg or -light-1024.png.
- Dark-mode app tiles: choose a filename ending in -dark.svg or -dark-1024.png.
- favicon/ contains a dark default favicon plus a light alternate.

FOLDERS
- svg/: Transparent marks, monochrome marks, and light/dark square, rounded-square, and circle vectors.
- png/: 1024 px exports of every SVG master.
- favicon/: Browser favicons, Apple touch icons, Android icons, maskable icon, pinned-tab vector, and web manifest.
- social/: Ready-to-use 1024 px light- and dark-mode avatars.

All SVG artwork uses the same clean Bézier curves, rounded construction, and approved heavier stroke weight as the complete BIOS logo master. No fonts or linked images are required.
